# 数据字典

本数据字典用于详细说明系统所有数据库表的字段含义、数据类型、约束和业务说明。组员可以直接参考该文件理解表结构与设计逻辑。

## User（用户表）

| 字段名 | 数据类型 | 说明 | 约束/默认值 |
| --- | --- | --- | --- |
| user_id | VARCHAR(20) | 学号或工号，用户唯一标识 | 主键 |
| name | VARCHAR(50) | 姓名 | NOT NULL |
| password | VARCHAR(255) | 登录密码 | NOT NULL |
| phone | VARCHAR(20) | 联系电话 | 可空 |
| email | VARCHAR(100) | 邮箱 | 可空 |
| role | ENUM('ADMIN','TEACHER','STUDENT') | 用户角色 | NOT NULL |
| status | ENUM('ACTIVE','DISABLED') | 用户状态 | NOT NULL 默认 'ACTIVE' |

说明：`User` 表既存储管理员，也存储教师和学生。`role` 字段区分不同身份。

## Classroom（教室表）

| 字段名 | 数据类型 | 说明 | 约束/默认值 |
| --- | --- | --- | --- |
| classroom_id | INT | 教室编号 | 主键，自增 |
| building | VARCHAR(50) | 所属楼宇 | NOT NULL |
| room_number | VARCHAR(20) | 房间号 | NOT NULL |
| capacity | INT | 教室容量 | NOT NULL，CHECK(capacity > 0) |
| floor | INT | 所在楼层 | NOT NULL，CHECK(floor >= 0) |
| status | ENUM('AVAILABLE','MAINTENANCE') | 教室状态 | NOT NULL 默认 'AVAILABLE' |

说明：`Classroom` 的 `(building, room_number)` 必须唯一，用于保证同一楼宇下房间号不重复。

## Device（设备表）

| 字段名 | 数据类型 | 说明 | 约束/默认值 |
| --- | --- | --- | --- |
| device_id | INT | 设备编号 | 主键，自增 |
| device_name | VARCHAR(50) | 设备名称 | NOT NULL |
| device_type | VARCHAR(50) | 设备类别 | NOT NULL |
| description | TEXT | 设备描述 | 可空 |

说明：存储教室中可能存在的设备类型，例如投影仪、空调、音响、电脑、电子白板等。

## Classroom_Device（教室设备关联表）

| 字段名 | 数据类型 | 说明 | 约束/默认值 |
| --- | --- | --- | --- |
| id | INT | 关联记录编号 | 主键，自增 |
| classroom_id | INT | 对应教室编号 | 外键，关联 `Classroom(classroom_id)` |
| device_id | INT | 对应设备编号 | 外键，关联 `Device(device_id)` |
| quantity | INT | 设备数量 | NOT NULL 默认 1，CHECK(quantity > 0) |

说明：`Classroom_Device` 是教室与设备之间的多对多关系表，记录某教室拥有某种设备的数量。

## Course（课程表）

| 字段名 | 数据类型 | 说明 | 约束/默认值 |
| --- | --- | --- | --- |
| course_id | INT | 课程编号 | 主键，自增 |
| course_name | VARCHAR(100) | 课程名称 | NOT NULL |
| teacher_id | VARCHAR(20) | 任课教师编号 | 外键，关联 `User(user_id)` |

说明：一个教师可以教授多门课程，`teacher_id` 指向教师身份用户。

## Schedule（课程安排表）

| 字段名 | 数据类型 | 说明 | 约束/默认值 |
| --- | --- | --- | --- |
| schedule_id | INT | 排课编号 | 主键，自增 |
| course_id | INT | 课程编号 | 外键，关联 `Course(course_id)` |
| classroom_id | INT | 教室编号 | 外键，关联 `Classroom(classroom_id)` |
| weekday | TINYINT | 星期（1-7） | NOT NULL，CHECK(weekday BETWEEN 1 AND 7) |
| start_period | TINYINT | 起始节次 | NOT NULL，CHECK(start_period BETWEEN 1 AND 13) |
| end_period | TINYINT | 结束节次 | NOT NULL，CHECK(end_period BETWEEN 1 AND 13) |
| start_week | INT | 起始周 | NOT NULL，CHECK(start_week > 0) |
| end_week | INT | 结束周 | NOT NULL，CHECK(end_week > 0) |

说明：`Schedule` 表表示课程在指定周次、星期和节次范围内固定占用某教室。

## Reservation（预约表）

| 字段名 | 数据类型 | 说明 | 约束/默认值 |
| --- | --- | --- | --- |
| reservation_id | INT | 预约编号 | 主键，自增 |
| user_id | VARCHAR(20) | 申请人编号 | 外键，关联 `User(user_id)` |
| classroom_id | INT | 教室编号 | 外键，关联 `Classroom(classroom_id)` |
| reservation_date | DATE | 预约日期 | NOT NULL |
| start_period | TINYINT | 起始节次 | NOT NULL，CHECK(start_period BETWEEN 1 AND 13) |
| end_period | TINYINT | 结束节次 | NOT NULL，CHECK(end_period BETWEEN 1 AND 13) |
| purpose | VARCHAR(255) | 使用用途 | NOT NULL |
| apply_time | DATETIME | 申请时间 | NOT NULL 默认 CURRENT_TIMESTAMP |
| status | ENUM('PENDING','APPROVED','REJECTED','CANCELLED') | 审核状态 | NOT NULL 默认 'PENDING' |

说明：`Reservation` 表用于记录教室预约申请，`status` 表示当前审核流程状态。冲突检测时，`PENDING` 和 `APPROVED` 都会占用教室资源；`REJECTED` 和 `CANCELLED` 不再参与冲突判断。

## Reservation_Audit（预约审核表）

| 字段名 | 数据类型 | 说明 | 约束/默认值 |
| --- | --- | --- | --- |
| audit_id | INT | 审核编号 | 主键，自增 |
| reservation_id | INT | 对应预约编号 | 外键，关联 `Reservation(reservation_id)` |
| admin_id | VARCHAR(20) | 审核管理员编号 | 外键，关联 `User(user_id)` |
| audit_time | DATETIME | 审核时间 | NOT NULL 默认 CURRENT_TIMESTAMP |
| audit_result | ENUM('APPROVED','REJECTED') | 审核结果 | NOT NULL |
| audit_comment | VARCHAR(255) | 审核意见 | 可空 |

说明：审核记录表用于追踪每次预约审批操作，并通过触发器同步更新 `Reservation.status`。

## 枚举说明

- `User.role`：`ADMIN`、`TEACHER`、`STUDENT`
- `User.status`：`ACTIVE`、`DISABLED`
- `Classroom.status`：`AVAILABLE`、`MAINTENANCE`
- `Reservation.status`：`PENDING`、`APPROVED`、`REJECTED`、`CANCELLED`
- `Reservation_Audit.audit_result`：`APPROVED`、`REJECTED`

## 关系说明

- `Course.teacher_id` 连接教师用户
- `Schedule.course_id` 连接课程
- `Schedule.classroom_id` 连接教室
- `Reservation.user_id` 连接申请人
- `Reservation.classroom_id` 连接预约教室
- `Reservation_Audit.reservation_id` 连接预约记录
- `Reservation_Audit.admin_id` 连接审核管理员

## 约束与注意事项

1. `Classroom` 中 `building` 与 `room_number` 组合必须唯一。
2. `start_period <= end_period` 与 `start_week <= end_week` 是节次和周次范围合法性的基础规则。
3. `Reservation` 中 `status` 为 `PENDING` 或 `APPROVED` 的记录会参与冲突检测，防止待审核申请和已通过预约被重复占用。
4. `Classroom_Device.quantity` 必须大于 0，以保证设备数量合理。
